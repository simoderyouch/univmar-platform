UNIVMAR — PHASE 11: DOCUMENTS & AUDIT HISTORY

STATUS

Phase 11 is complete. It introduces a reusable record-file workspace and a
shared activity trail for attached documents and invoice workflow actions.

DOCUMENTS

Files can be attached to customers, projects, RFQs, quotations, orders,
deliveries, and invoices. Supported file types are PDF, Word, Excel, CSV,
JPEG, PNG, and WebP, with a maximum size of 20 MiB.

Each attachment records its document type, original file name, file URL,
content type, size, uploader, and creation time. Users can open/download or
remove an attachment from the Documents & activity workspace.

AUDIT HISTORY

The shared activity timeline records document attachment/removal actions and
invoice creation, issuance, payment recording, and voiding. Existing RFQ and
order timelines continue to provide their detailed workflow history.

INTERFACE

The Documents workspace lets the user choose a record type and a specific
record, then manage its files beside an activity timeline. This keeps drawings,
commercial documents, delivery notes, and other supporting material with the
business record they belong to.

DATA

Migration V14 creates business_document and audit_event. Document links use a
typed record reference so one reusable module can support the platform without
duplicating attachment tables for every feature.
